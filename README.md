# 🧪 NaSalinha - Auditoria de Qualidade (QA)

Este repositório contém a documentação completa de testes, relatórios de bugs e artefatos do desafio de Quality Assurance para o projeto **NaSalinha**.

## 🎯 Tipos de Testes Aplicados
* **Testes Funcionais (Manual/UI):** Validação das telas e fluxos de usuário.
* **Testes de API:** Validação dos endpoints, contratos, payloads e Status Codes.
* **Testes de Regressão:** Garantia de que correções de bugs não afetaram o sistema existente.
